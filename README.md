# CS2A Помощник — Android

Перенос Chrome-расширения «CS2A Помощник» на Android: ферма (яйцо раз в сутки), кэшбек,
автоучастие в розыгрышах и спам в чат — без постоянно открытого Chrome.

## Сборка .apk

APK собирается автоматически через GitHub Actions при каждом push в `main` (или вручную —
вкладка **Actions → Build APK → Run workflow**). Готовый файл забирается из **Actions → (последний
прогон) → Artifacts → cs2a-helper-debug-apk**. Это debug-сборка без подписи релизным ключом —
для личной установки этого достаточно (разрешите «Установка из неизвестных источников»).

## Как пользоваться

1. Установите .apk, откройте приложение.
2. Вкладка **Статус** → «Войти на cs2a.run» — откроется окно сайта, войдите в свой аккаунт как
   обычно. Токен (JWT) подхватится сам из `localStorage` сайта — так же, как это делает сам сайт.
3. Вкладка **Авто** — настройте сумму, множитель автовывода и число раундов. ÷2 / ×2 меняют ставку, ALL IN перед каждой ставкой заново читает `data.auth.wallet.balance`. Нажмите «Старт»: отдельная foreground-служба открывает WebView и слушает `csgorun:crash`; ставка отправляется только при `status:1`, максимум один раз на ID раунда. Служба остановится после заданного числа ставок, при недостаточном балансе, ошибке API или вручную. ALL IN расходует весь доступный баланс и может привести к полной потере средств.
4. Вкладка **Ферма** — выберите яйцо, включите «Автозабор» и «Автокэшбек» (оба срабатывают раз
   в сутки в 03:00 МСК, через `AlarmManager`, независимо от того, открыто приложение или нет).
5. Вкладка **Розыгрыши** — включите общий тумблер автоучастия (или жмите «Участвовать» вручную
   по каждому). Повтор — свой цикл у каждого розыгрыша (час/день/неделя/месяц), тоже через будильники.
6. Вкладка **Спам** → «Обучить формат» — откроется то же окно сайта: один раз напишите любое
   сообщение в чат вручную. Приложение запомнит формат запроса и перенесёт его в фоновую службу.
   Затем впишите сообщение и паузу, «Запустить». Автостоп — как в расширении: приложение следит
   за ответом сайта (`{data:{stopped:true}}` / `{failed:true}`), а не только за словами.
7. Вкладка **Статус** → «Отключить ограничение батареи» — обязательно сделайте это, иначе Android
   может «усыплять» фоновую службу спама и отменять точные будильники.

## Важное ограничение: спам в фоне

Автоставки Crash требуют активной WebSocket-сессии сайта в отдельной foreground-службе. Ферма/кэшбек/розыгрыши — чистые HTTP-запросы по расписанию.

Спам в чат устроен иначе: внутри фоновой службы крутится скрытый `WebView` с реальной страницей
cs2a.run (только так можно знать актуальный формат WebSocket/HTTP запроса чата и ловить сигнал
остановки в реальном времени). Android может ограничивать работу такого WebView, если:
- включена агрессивная экономия батареи (решается шагом 6 выше, и дополнительно — в настройках
  производителя: Xiaomi/MIUI, Huawei и т.п. часто имеют свой отдельный список автозапуска);
- приложение не запускалось долго, или было принудительно остановлено («Force stop») — это
  полностью убивает службу, автозапуск после перезагрузки телефона есть, а после Force Stop — нет
  (так работает сама Android, это нельзя обойти).

Если спам всё равно останавливается сам по себе без причины — откройте приложение раз в день,
это сбрасывает таймер бездействия Android для приложения.

## Структура проекта

- `app/src/main/java/ru/cs2a/helper/` — Kotlin: UI (`MainActivity`, `LoginActivity`), сетевой слой
  (`Api.kt`, повторяет `authedFetch()`/`cashbackAttempt()`/`farmEggAttempt()`/`doLottery()` из
  `background.js` расширения), каталоги (`Catalog.kt` — те же `LOTTERIES`/`FARM_EGGS`), будильники
  (`alarm/`), фоновая служба спама (`spam/SpamForegroundService.kt`).
- `app/src/main/assets/cs2a_inject.js` — слитые `page/core.js` + `page/spam.js` + `content/chat.js`
  из расширения, адаптированные под единый JS-мир WebView (мост `AndroidBridge` вместо
  `window.postMessage` между мирами расширения).
